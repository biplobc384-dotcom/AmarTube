## 🔥 Key Features

### 🚀 Multi-Engine Media & File Downloader
- **YouTube & SoundCloud Extraction**: Powered by **NewPipe Extractor** with fallback to **Piped API** and **Invidious API**.
- **TikTok No-Watermark Downloader**: Download TikTok HD videos without watermark + original MP3 audio via **TikWM Engine**.
- **Social Media Downloader**: Download high-quality videos from Facebook, Instagram, Twitter/X, and YouTube via **Cobalt Universal Engine**.
- **18+ & Adult Site Video Extractor**: Script/JSON regex parser for platforms like xVideos, xHamster, Pornhub, SpankBang, and Eporner.
- **Direct Web File Interceptor**: Automatically captures direct file downloads (`.apk`, `.pdf`, `.zip`, `.mp4`, `.mp3`, `.mkv`) clicked in the built-in browser.

### 🌐 Smart In-App Browser
- Integrated **WebView** with JavaScript DOM Sniffer for `<video>`, `<source>`, and `<meta property="og:video">` tags.
- Direct File Download Listener for instant intercepetion of links clicked while browsing.
- Download options sheet displaying resolution badges (`FHD`, `HD`, `MP4`, `MP3`, `APK`, `ZIP`) and file sizes.

### 🎧 Advanced Media Player
- Built with **Jetpack Media3 (ExoPlayer)**.
- **Background Audio Playback**: Keep listening to music/audio when the app is minimized or the screen is turned off.
- Floating Mini-Player and PiP support for multitasking.

### 🔄 GitHub In-App Auto-Updater & Installer
- Automatic check on app launch via **GitHub Releases API**.
- User-friendly in-app update prompt with release notes and real-time APK download progress bar.
- One-click seamless package installation using `FileProvider`.
- Smart **12-Hour Request Throttling** to prevent GitHub API rate limits.
